# MediVault 💊

MediVault is a lightweight, 100% secure web application designed for tracking personal and family medicine inventories directly in your browser. Built with a privacy-first approach, it ensures your sensitive health data never leaves your device. 

## Key Features

*   **Zero-Server Privacy:** All data is saved strictly to your device's browser using local storage, requiring no backend servers or external databases. 
*   **Automated Depletion Math:** Intelligently calculates exactly how many days your stock will last and outputs the exact calendar depletion date based on your dosage routines.
*   **Dynamic Family Profiles:** Instantly switch between separate, isolated vaults (e.g., My Vault, Mom's Prescriptions) with support for up to 5 customizable profiles.
*   **Flexible Routines & SOS Mode:** Track medicines by scheduled routines (Morning, Noon, Night) or mark them as "SOS" for as-needed consumption. Features 1-Click Bulk Logging to instantly deduct entire daily routines.
*   **Batch & Expiry Tracking:** Add multiple batches of the same medicine. The system automatically groups them, sorts by expiry date, and intelligently deducts from the oldest batch first.
*   **Bulletproof JSON Backups:** Export your entire vault as a lightweight `.json` file and restore it seamlessly across devices or after a browser history wipe.
*   **Printable Refill Lists:** Automatically flags low stock (under 14 days supply) and generates a clean, printable HTML table to take to the pharmacy.
*   **Archive System:** Hide old, discontinued, or fully depleted medicines from your active dashboard without permanently deleting the record.

## Technology Stack

*   **Core:** Vanilla HTML5, CSS3, and Modern JavaScript (ES6+).
*   **Methodology:** Built as a hobby project leveraging the power of Prompt Engineering & AI.
*   **Hosting:** GitHub Pages.

## Local Setup & Deployment

To run or modify the application locally:
1. Clone or download the repository.
2. Open `index.html` directly in any modern desktop or mobile browser.
3. To host it yourself, push the file to a GitHub repository and enable GitHub Pages under the repository settings.
